# Claim-language guardrails

| Prefer | Avoid |
|---|---|
| associated with | caused by; driven by disease unless formally established |
| cohort-specific community structure | universal disease signature |
| qualified ecological generalizability | replication; validation; independent confirmation |
| two independently analyzed cohorts | multicenter study |
| 530-report technical universe | one 530-person diagnosis cohort |
| classifier yield / classified fraction | bacterial load; bacterial biomass |
| classifier-defined direct-species subcomposition | complete microbiome or absolute community |
| location and/or dispersion structure | centroid separation when PERMDISP is material |
| shared observability | replicated taxa |
| descriptive side-by-side synthesis | formal meta-analysis |
| exploratory differential abundance, if later authorized | biomarkers or diagnostic taxa |

Every numerical placeholder must be populated from schema-valid formal output. Null results remain null; sensitivity thresholds cannot be selected by favorable P values. No causal, diagnostic or predictive claim is permitted without a different design and evidence base.
