# Prospective formal cross-cohort analysis plan

This plan is frozen during workstation downtime. It prepares, but does not execute, biological analysis. `BIOLOGICAL_ANALYSIS_EXECUTED=false`. The previously queued isolated installation of zCompositions 1.6.2 has unknown status and is neither assumed complete nor changed here. No ETYY connection or job was used.

The analytical universe contains two separate cohorts: PRJNA1056765 (400 unique BALF patients) and PRJCA046985 (130 unique BALF subjects). The former estimates a four-level published-diagnosis association; the latter estimates a Drug_Resistance versus Drug_Sensitive TB association. They are not one clinical estimand. Matrices will never be pooled, and coefficients or P values will not be combined.

## Input definition

Only Kraken2 species-rank direct-assigned counts from the verified common classifier-assignment handoff are allowed. Clade counts and Bracken estimates are prohibited. Alpha metrics use the complete direct-species count vector before prevalence filtering. Classified fraction is `classified_reads / total_input_reads` from the paired Kraken2 report QC and is a technical endpoint, not bacterial biomass.

Direct-species composition is a classifier-defined subcomposition. It describes relative organization among classifier-assigned species and cannot estimate absolute microbial load.

## Primary compositional analysis

For each cohort independently:

1. Compute detection as direct count greater than zero.
2. Retain a feature when its within-cohort prevalence is at least 10%, inclusive at the boundary. Remove every all-zero taxon.
3. Apply the exact `zCompositions::cmultRepl` implementation from zCompositions 1.6.2 with `label=0`, `method="CZM"`, `output="prop"`, `frac=0.65`, `threshold=0.5`, and `adjust=TRUE`.
4. Require R 4.5.3 and resolve zCompositions, NADA and truncnorm inside `/mnt/disk1/0714_control/r_libs/zCompositions-1.6.2-R-4.5.3`, with that directory first in the effective `.libPaths()`. Record all versions and resolved paths; fail closed on any mismatch. No local approximation is permitted.
5. Close every positive replaced vector to sum one, take its centered log-ratio, and calculate Euclidean distance in CLR space (Aitchison distance).
6. Run cohort-specific PERMANOVA with 9,999 permutations and paired PERMDISP with 9,999 permutations on the identical samples and distance matrix.

PERMDISP uses distances from each sample to its observed group centroid in Euclidean Aitchison space. Its observed F statistic is the one-way ANOVA of those distances. The permutation null is generated by fitting that fixed one-way model, permuting its least-squares residuals under the cohort-specific exchangeability restriction, refitting the same design and recomputing F. Group labels and centroids are not recomputed during permutations. This follows the Anderson/`vegan::permutest.betadisper` centroid residual-permutation concept, but numerical equality to vegan is claimed only when the same distance matrix and explicit permutation matrix have been compared.

The deterministic primary seed registry is: anchor PERMANOVA `105676510`, anchor PERMDISP `105676511`, external PERMANOVA `46985010`, and external PERMDISP `46985011`. Non-primary CZM filter cells add prevalence multiplied by 10,000; pseudocount cells add `100000` plus prevalence multiplied by 10,000. Seeds are recorded in every result.

## Prespecified sensitivities

Repeat the complete cohort-specific analysis at prevalence thresholds 5% and 20%. Repeat the 5%, 10% and 20% grid using an **additive pseudocount**: add exactly 0.5 direct read to every retained feature count, including positive counts, before closure and CLR. Output records `zero_method=additive_pseudocount`, `pseudocount=0.5` and `applied_to=all_retained_features`. This sensitivity may never replace a missing CZM primary. Threshold or zero method will not be selected from observed results.

Bray-Curtis is one technical sensitivity per cohort: retain the cohort-specific 10% feature set, convert each retained direct-species count vector to sample-wise proportions, apply no zero replacement, and run the same 9,999-permutation PERMANOVA plus residual-permutation PERMDISP. For this non-Euclidean sensitivity only, the Anderson/vegan signed squared distance-to-centroid expression is used; negative values are changed to zero and their count is serialized. It is not crossed with 5%/20% filters or either zero method. The existing 999-permutation artifact remains separate provenance and is not overwritten.

The anchor collection-year sensitivity is `Aitchison distance ~ collection_year + diagnosis`, with the marginal diagnosis term evaluated by a reduced-model residual-permutation procedure within Training/Test blocks. It runs only if collection year is deterministic and non-missing, all diagnosis-by-year and diagnosis-by-block representation checks pass, and the model matrix is full rank; otherwise it is recorded as `NOT_RUN_DESIGN_GATE`. The external nominal-length sensitivity is `Aitchison distance ~ nominal_read_length + resistance_status`, with the marginal resistance-status term tested by reduced-model residual permutation. It requires deterministic 50/75-nt labels, both resistance groups represented at least twice in each length category, and full rank; otherwise it is `NOT_RUN_DESIGN_GATE`. These are technical sensitivities, not primary adjustments, and are not yet assumed runnable.

## Primary tests and secondary endpoints

The anchor primary test is the four-level diagnosis omnibus. The external primary test is the binary resistance-status association. Report pseudo-F, point R², permutation P, group sizes, seed, feature count and dispersion result. No confidence interval is claimed for PERMANOVA R², PERMDISP eta-squared or rank-biserial effects. Uncertainty is represented by complete prespecified representation sensitivity, permutation P values and group-level centroid-distance summaries; no bootstrap was added without a separately justified design.

Secondary endpoints are richness, Shannon entropy, Gini-Simpson diversity, dominance and classified fraction. Richness is sequencing-effort sensitive; classified fraction does not resolve its dependence on direct-species assigned depth. These endpoints are interpreted only with sample-level sequencing/classification QC. The anchor uses a Kruskal-Wallis omnibus with epsilon-squared. The three frozen contrasts are Lung cancer minus Bacterial infection, Lung cancer minus Fungal infection and Lung cancer minus Pulmonary tuberculosis; positive rank-biserial values mean larger values in Lung cancer. All 15 tests are calculated as a fixed reproducibility family. Confirmatory interpretation is endpoint-specific and allowed only when that endpoint's four-level omnibus is significant after Holm adjustment across the five omnibus tests; otherwise the pairwise result remains explicitly descriptive. The external direction is Drug_Resistance minus Drug_Sensitive; positive rank-biserial values mean larger values in Drug_Resistance.

Zero handling produces descriptive QC only: zero fractions per sample and taxon, retained-feature count, number/fraction of replaced cells and sample-wise total-variation perturbation between the raw retained-count closure and replaced closure. These diagnostics never exclude samples or select a method.

## Multiplicity and serialization

Primary PERMANOVA questions are reported as two distinct cohort-specific estimands, not a pooled family. Holm adjustment controls the 15 anchor secondary contrast tests (three contrasts by five endpoints) and the five external secondary endpoint tests. Benjamini-Hochberg is reserved for later, separately authorized taxon-level exploratory families, separately by cohort, rank and test family.

Each cohort/cell produces schema-validated JSON plus compact TSVs for sample metrics, feature-filter counts, beta statistics, secondary tests, zero diagnostics and figure inputs. Aitchison cells also serialize deterministic PCA-of-CLR ordination coordinates, which are equivalent to Euclidean Aitchison PCoA coordinates. JSON and custom cross-field checks reject NaN/Inf, inconsistent sample/group counts, duplicate sample IDs, wrong cohorts, methods, orientations, seeds or permutation counts, and incomplete method provenance. Output is first written to a `.partial` directory and promoted only after a completion marker is written. The checked-in schema is `result_schema.json`.

## Interpretation and execution gate

A PERMANOVA signal with material PERMDISP evidence is described as location and/or dispersion structure (`DISPERSION_QUALIFIED`), not a clean centroid shift. Null or very small effects remain reportable. Formal analysis begins only after ETYY recovery confirms the old installation state, exact zCompositions 1.6.2 behavior on a synthetic vector, immutable inputs and a separately visible formal-analysis authorization. Differential abundance remains exploratory and is not automatically authorized by this plan.
